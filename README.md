# GitHub 国内加速器（Chrome / Edge 扩展）

进入 GitHub 时自动把 **raw 文件、Releases 附件、源码打包（archive / Download ZIP / codeload）、gist** 等高延迟请求重定向到自选加速线路；支持一键测速、下载测速、流量/时长统计、动态图标、全站镜像与自定义线路。

## 功能

- 🟢 **动态图标**：加速中显示**绿色闪电**，待命/直连显示**黑色闪电**，状态一眼可辨（悬停显示当前状态与线路）
- 🤖 **自动加速**：打开任一 GitHub 页面自动启用加速，**关闭所有 GitHub 页面后自动停止**（可在弹窗开关）
- 🚀 **一键加速**：选择线路即生效，浏览器内访问 GitHub 的下载类请求自动走所选线路
- 🔀 **自由选线**：两类线路，点图标即可切换
  - **加速前缀**（推荐）：页面仍走官方 github.com，只加速文件类请求，不影响登录和页面功能
  - **全站镜像**：github.com 整站跳转到镜像站，浏览更快，但镜像站随时可能失效
- ⚡ **一键测速**：并发测各线路延迟，自动切换到最快的可用线路
- 📈 **下载测速**：测速后对当前线路做真实下载采样（最多 2.5 秒），显示下载速度
- 📊 **统计小栏**：今日加速流量（估算）、实时速度（最近 10 秒）、加速时长，一键清零
- 🛠 **可定制**：添加自定义前缀 / 镜像线路；内置线路可在弹窗中用 JSON 编辑更新
- 🎯 **可选加速项**：头像（avatars）、页面静态资源（githubassets）默认关闭，可在弹窗开启

## 安装（免打包，开发者模式加载）

1. 把本目录放到本地任意位置（即包含 `manifest.json` 的文件夹）
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角 / 侧边的 **「开发者模式」**
4. 点击 **「加载已解压的扩展程序」**，选择本目录
5. 在工具栏固定扩展图标，点图标即可选线路、测速

> 从 1.0 升级：先「移除」旧版再重新加载本目录，或在扩展管理页点「重新加载」。

## 使用

- **自动加速（默认开启）**：弹窗顶部的「🤖 自动加速」开关控制——
  - 打开任一 GitHub 相关页面（github.com / githubusercontent.com，全站镜像模式下含镜像域名）→ 自动启用所选线路加速
  - **关闭所有 GitHub 页面 → 自动停止加速**（状态变为「待命中」，图标变回黑色）
  - 关闭它则始终按所选线路加速（经典模式）
- **选线路**：点扩展图标，点任一线路行即切换，立即生效（所有 GitHub 标签页都会应用）。
- **测速**：点「⚡ 测速并切换最快线路」→ 先测全部线路延迟并自动启用最快的 → 再对当前线路做下载速度采样，结果显示在列表下方。
- **统计栏**：顶部三项实时刷新——
  - *今日流量**：经加速线路的响应字节数（按响应头 `content-length` 估算，分块传输不计入，仅供参考）
  - *实时速度*：最近 10 秒经加速线路的实际速率
  - *加速时长*：加速线路连续启用时长（切到直连即清零）
  - 右侧 ↺ 可清零今日统计
- **添加自定义线路**：展开「➕ 添加自定义线路」
  - *加速前缀*：填一个支持 `https://前缀/https://github.com/...` 形式的代理地址
  - *全站镜像*：填域名映射 JSON，例如 `{"github.com": "mirror.example.com", "raw.githubusercontent.com": "raw.mirror.example.com"}`
- **更新内置线路**：展开「高级：编辑全部线路（JSON）」直接改，保存即生效。

## 终端 git 命令加速（扩展管不到的地方）

扩展只作用于浏览器。命令行克隆可手动给 URL 加前缀：

```bash
git clone https://ghfast.top/https://github.com/owner/repo.git
```

`git push`、SSH 方式不受影响也无需加速。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 图标是黑色、状态「待命中」 | 自动加速模式下没有打开的 GitHub 页面，正常行为；打开任一 GitHub 页面立即变绿 |
| 打开 GitHub 的第一个请求没加速 | 自动加速在页面打开瞬间生效（约 0.25 秒内），极快的首个请求可能直连，刷新即可 |
| 无痕窗口不触发自动加速 | 扩展默认未授权无痕模式，需在扩展详情页勾选「在无痕模式下启用」 |
| 测速全部超时 | 公共线路可能全挂了或被墙，在「添加自定义线路」里填入可用的前缀/镜像 |
| 图标没变绿 | 工具栏角标按当前线路实时切换；若是刚加载扩展，点一下图标选线路即可 |
| 实时速度一直显示 — | 统计按「最近 10 秒经加速线路的流量」计算，没有下载时显示 — 是正常的 |
| 流量数字偏小 | 按 `content-length` 估算，分块传输（chunked）不计入，仅供参考 |
| 镜像站页面样式错乱 | 镜像站自身问题，换一条线路或用「官方直连」 |
| 头像/样式没加速 | 默认关闭（部分线路不支持导致破图），可在弹窗开关开启 |
| 某个 GitHub 域名没被加速 | 前缀模式只匹配常见下载类域名，可在 `common.js` 的 `PREFIX_TARGETS` 里加一条后重载扩展 |
| 修改了 `common.js` 默认线路 | 在扩展管理页点该扩展的「重新加载」生效 |

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `declarativeNetRequest` | 重定向 GitHub 请求到所选线路 |
| `webRequest`（只读响应头） | 本地统计经加速线路的流量/请求数，**不上传任何数据** |
| `tabs` | 仅统计「当前打开了多少个 GitHub 标签页」，用于自动加速的启停判断，不读取页面内容 |
| `storage` | 保存线路配置（local）与统计（session，关浏览器即清） |
| `host_permissions: <all_urls>` | 允许重定向到任意自选线路目标（弹窗里添加的自定义线路） |

## 安全与隐私

- 扩展**不收集、不上传任何数据**；网络请求只有你主动点「测速」时的探测/采样
- 规则只重定向 GitHub 相关域名（`github.com` / `githubusercontent.com`）
- ⚠️ 第三方公共加速/镜像服务可以看到你请求的文件内容：**不要在镜像站登录账号，不要用它访问私有仓库的敏感内容**

## 目录结构

```
github-accelerator/
├── manifest.json      # 扩展清单（MV3）
├── common.js          # 线路配置 + 规则构建 + 统计助手（默认线路在这里改）
├── background.js      # Service Worker：规则/图标 + webRequest 流量统计
├── popup.html/css/js  # 弹窗：状态、统计栏、选线、测速、自定义线路
├── icons/             # 绿色（加速）/ 黑色（直连）两套图标
├── tools/make-icons.ps1   # 图标生成脚本（PowerShell）
└── userscript-github-mirror.user.js  # 附：油猴轻量版
```

## 附：油猴轻量版

`userscript-github-mirror.user.js` 是给**不能装扩展的环境**用的 Tampermonkey 脚本：打开 github.com 时自动跳转到所选镜像站（油猴菜单里选线路）。

局限：脚本无法拦截页面内部的 fetch/XHR 请求，所以 raw、Releases 下载、克隆等场景请用扩展版。

> 仅供个人学习与日常使用；公共线路的可用性不受本工具控制。
